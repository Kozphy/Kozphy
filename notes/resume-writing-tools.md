# Resume Writing Tools

This note compares practical tools for writing, improving, tailoring, and exporting a professional resume.

## Recommended Tools

| Tool | Best for | Free option |
|---|---|---|
| **ChatGPT Resume Builder** | Analysing, rewriting, and improving an existing resume | Available in ChatGPT when you upload a PDF or DOCX resume |
| **Teal Resume Builder** | Managing several job-specific resume versions and matching them against job descriptions | Core resume-building features are available for free |
| **Rezi** | ATS-friendly resumes, keyword targeting, and AI-assisted bullet writing | A free plan is available with usage limits |
| **FlowCV** | Creating a clean and attractive resume with simple formatting | The first resume can be created for free |
| **Reactive Resume** | Privacy, customization, and open-source resume creation | Free and open-source |

## Recommended Workflow

### 1. Create a master resume

Keep one complete version containing all of your:

- Education
- Work experience
- Independent projects
- Technical skills
- Certifications
- Achievements
- Volunteer or extracurricular experience

The master resume can be longer than the version you send to employers. Its purpose is to preserve all useful information.

### 2. Create role-specific versions

Do not use exactly the same resume for every application. Build separate versions for different career directions.

For example:

- Accounting and finance
- Data analytics and business intelligence
- Technology risk and IT audit
- Software engineering and automation
- AI and data engineering

Each version should prioritize the experience and keywords most relevant to the target role.

### 3. Match the job description

Before applying, compare the resume with the job description and identify:

- Required skills
- Preferred tools and technologies
- Industry terminology
- Expected responsibilities
- Seniority level
- Important certifications

Use the same accurate terminology where it genuinely matches your experience. Do not add skills or achievements you cannot explain in an interview.

### 4. Improve experience bullets

A strong resume bullet normally includes:

**Action + task + method + result**

Weak example:

> Responsible for financial data processing.

Stronger example:

> Automated financial-data cleaning and reconciliation workflows using Python and Excel, reducing repetitive manual processing and improving reporting consistency.

Add numbers when they are accurate and defensible, such as:

- Number of users
- Number of records processed
- Number of modules built
- Time saved
- Error reduction
- Revenue impact
- System performance
- Number of tests passed

### 5. Check ATS compatibility

Applicant tracking systems generally work best with simple formatting.

Recommended:

- One-column layout
- Standard section headings
- Clear dates and job titles
- Common fonts
- Consistent bullet formatting
- Text-based PDF or DOCX

Avoid:

- Important information placed only in images
- Complex multi-column layouts
- Skill-rating bars
- Large icons
- Decorative charts
- Excessive colours
- Headers or footers containing essential contact information

### 6. Export and review

Before submitting the resume:

- Check spelling and grammar
- Confirm all dates are consistent
- Verify email, phone number, LinkedIn, and GitHub links
- Make sure project links are public and working
- Confirm the PDF text can be selected and copied
- Use a professional filename

Example filename:

```text
Zixsa_Lee_Technology_Risk_Resume.pdf
```

## Best Tool Combination

A practical combination is:

1. **ChatGPT Resume Builder** for analysis and rewriting
2. **Teal** for managing multiple job-specific versions
3. **Rezi** for ATS and keyword checks
4. **FlowCV** or **Reactive Resume** for final formatting and export

## Recommendation for an Accounting and Technology Profile

For a background combining accounting, finance, Python, SQL, Power BI, technology risk, and software projects, maintain at least three resume versions.

### Accounting and Finance Resume

Emphasize:

- Accounting education
- Financial reporting
- Tax or audit exposure
- Excel and reconciliation
- Internal controls
- Financial-data automation

### Data and Technology Risk Resume

Emphasize:

- Python, SQL, Excel, and Power BI
- Data pipelines and reporting
- Audit evidence and control testing
- Risk analytics
- Data validation and governance
- Automation projects

### Software and AI Resume

Emphasize:

- System design
- APIs and databases
- Testing and CI/CD
- Cloud or containerization
- AI evaluation and automation
- GitHub portfolio projects

## Important Principle

A resume should not try to include everything. Its job is to make the recruiter quickly understand:

1. What role you are targeting
2. What problems you can solve
3. What evidence proves your ability
4. Why your background matches the position

A focused, truthful, and easy-to-read resume is usually more effective than a highly decorative resume containing too much information.
